## 🏪 About JP Hardware

</div>

**JP Hardware** is a mobile-first, shopkeeper-friendly **Android Inventory & Shop Management System** engineered specifically for physical hardware and building-materials retailers (PVC pipes, iron ring rods / *sariya*, nuts, bolts, screws, taps, valves, and construction supplies).

Designed for non-technical shop owners, it replaces paper registers with **one-tap stock tracking**, **camera-based product cataloging**, **real-time gross profit insights**, and **automated low-stock alerts**—backed by atomic Cloud Firestore transactions so inventory counts never go out of sync.

```yaml
Project Name : JP Hardware (jp-hardware-stock)
Client       : JP Hardware Retail
Core Stack   : Kotlin · Android · Firebase Auth · Cloud Firestore
Currency     : Indian Rupees (₹) with IST (Asia/Kolkata) Reporting
Architecture : Atomic Transactions · Owner-Isolated Security Rules
